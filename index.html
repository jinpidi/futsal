🎯 Firebase 설정이 필요합니다

이 앱을 사용하려면 무료 Firebase 프로젝트를 한 번만 셋업해야 해요. 10분이면 끝납니다.

  1. Firebase 콘솔에 접속해 구글 로그인
  2. "프로젝트 만들기" → 이름 아무거나 (예: futsal-fc-seoulsoop) → 만들기
  3. 왼쪽 메뉴 "Build" → Realtime Database → "데이터베이스 만들기" → 위치는 아시아권 (예: Singapore) → 보안 규칙은 "테스트 모드" 선택
  4. 왼쪽 위 톱니바퀴 ⚙️ → "프로젝트 설정" → 아래쪽 "내 앱" 영역에서 </> (웹) 아이콘 클릭
  5. 앱 이름 입력 → "앱 등록" → firebaseConfig 객체가 나타나면 그걸 통째로 복사
  6. 이 HTML 파일을 텍스트 에디터로 열어서 FIREBASE_CONFIG firebaseConfig = { apiKey: "AIzaSyBkw9G2fKuV0P56OYvLB-G7A8lac0KDUL0", authDomain: "futsal-manager-pro.firebaseapp.com", databaseURL: "https://futsal-manager-pro-default-rtdb.asia-southeast1.firebasedatabase.app", projectId: "futsal-manager-pro", storageBucket: "futsal-manager-pro.firebasestorage.app", messagingSenderId: "256713523717", appId: "1:256713523717:web:990041b22e60fbf0d9526c" };

💡 끝났으면 페이지 새로고침. 그래도 이 화면이 보이면 FIREBASE_CONFIG 안에 databaseURL이 있는지 확인하세요. 없다면 Firebase 콘솔에서 Realtime Database를 다시 한번 만들어주세요.
